What Is Website

A website is a collection of interconnected web pages hosted on a web server and accessed via the internet using a single domain name or URL (like google.com).
It serves as a digital space to share information, sell products, or provide services.

What Is Webpage

A web page is a single digital document on the internet that you view through a web browser. It is written in languages like HTML and CSS, and can display text,
images, videos, and links to other pages. A collection of related web pages makes up a website.

    HTML:
    HTML stands for HyperText Markup Language and it is the standard language used to create and structure the framework of web pages. Think of it as the static skeleton
    or blueprint of a website. It tells your web browser (like Chrome or Safari) what content to display and how to organize it,
    such as identifying where a heading, paragraph, or image belongs.
    CSS:
    CSS stands for Cascading Style Sheets. It is a style sheet language used to define the visual presentation, formatting, and layout of a document written in a markup
    language like HTML. Along with HTML (which structures the content) and JavaScript (which adds functionality), CSS is a core
    foundational technology of the World Wide Web.
    JavaScript:
    JavaScript (JS) is a lightweight, cross-platform programming language used to create interactive and dynamic content on the internet. It is one of the core technologies of
    the World Wide Web, working alongside HTML (which defines content structure) and CSS (which handles visual styling). While
    HTML and CSS build static pages, JavaScript brings them to life by responding to user actions without reloading the page.
